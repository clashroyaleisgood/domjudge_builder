# DBM - 製作餅乾後剩下多少材料

### 題目敘述

小華想按照固定比例製作餅乾。

每做 1 份餅乾，需要：

- $f$ 公克的麵粉（flour）
- $m$ 公克的牛奶（milk）
- $s$ 公克的糖（sugar）

現在家裡有：

- $F$ 公克的麵粉
- $M$ 公克的牛奶
- $S$ 公克的糖

請你計算：

1. 最多可以製作幾份餅乾（允許小數）
2. 做完後剩下多少公克麵粉
3. 做完後剩下多少公克牛奶
4. 做完後剩下多少公克糖

> 製作份數由三種材料中最先用完的材料決定。

### 輸入說明

第一行包含一個整數 $f\ (1 \le f \le 1000)$，代表製作 1 份餅乾需要的麵粉公克數。

第二行包含一個整數 $m\ (1 \le m \le 1000)$，代表製作 1 份餅乾需要的牛奶公克數。

第三行包含一個整數 $s\ (1 \le s \le 1000)$，代表製作 1 份餅乾需要的糖公克數。

第四行包含一個整數 $F\ (1 \le F \le 10^6)$，代表目前擁有的麵粉公克數。

第五行包含一個整數 $M\ (1 \le M \le 10^6)$，代表目前擁有的牛奶公克數。

第六行包含一個整數 $S\ (1 \le S \le 10^6)$，代表目前擁有的糖公克數。

### 輸出說明

第一行輸出最多可以製作幾份餅乾。

第二行輸出剩下多少公克麵粉。

第三行輸出剩下多少公克牛奶。

第四行輸出剩下多少公克糖。

> 若結果有小數，請直接輸出計算結果。

### 範例輸入 #1

```
4
2
6
20
15
18
```

### 範例輸出 #1

```
3.0
8.0
9.0
0.0
```

### 範例說明 #1

三種材料可製作份數分別為：

- 麵粉：$20 \div 4 = 5.0$
- 牛奶：$15 \div 2 = 7.5$
- 糖：$18 \div 6 = 3.0$

因此最多只能做 3.0 份（糖最先用完）。

使用後剩餘：

- 麵粉：$20 - 3 \times 4 = 8.0$
- 牛奶：$15 - 3 \times 2 = 9.0$
- 糖：$18 - 3 \times 6 = 0.0$

### 範例輸入 #2

```
5
4

12

```

### 範例輸出 #2

```

0.0

```

### 範例說明 #2

三種材料可製作份數分別為：

- 麵粉：$12 \div 5 = 2.4$
- 牛奶：$20 \div 4 = 5.0$
- 糖：$30 \div 3 = 10.0$

因此最多只能做 2.4 份（麵粉最先用完）。
