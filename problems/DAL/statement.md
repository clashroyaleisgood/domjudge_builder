# DAL - 製作奶茶還需要多少牛奶

### 題目敘述

小美想按照固定比例製作奶茶。

每做 1 份奶茶，需要：

- $t$ 公克的紅茶（tea）
- $m$ 公克的牛奶（milk）

現在她手上有：

- $x$ 公克的紅茶
- $y$ 公克的牛奶

**已知目前的牛奶一定不足以配完所有紅茶。**

請你幫忙計算：

1. 這些紅茶最多可以製作幾份奶茶（允許小數）
2. 還需要再準備多少公克的牛奶，才能把紅茶全部用完

### 輸入說明

第一行包含一個整數 $t\ (1 \le t \le 1000)$，代表製作 1 份奶茶需要的紅茶公克數。

第二行包含一個整數 $m\ (1 \le m \le 1000)$，代表製作 1 份奶茶需要的牛奶公克數。

第三行包含一個整數 $x\ (1 \le x \le 10^6)$，代表目前擁有的紅茶公克數。

第四行包含一個整數 $y\ (1 \le y \le 10^6)$，代表目前擁有的牛奶公克數。

**題目保證目前牛奶一定不足，也就是需要額外購買牛奶。**

### 輸出說明

第一行輸出最多可以製作幾份奶茶。

第二行輸出還需要準備多少公克的牛奶。

若結果有小數，請直接輸出計算結果。

### 範例輸入 #1

```
4
10
14
20
```

### 範例輸出 #1

```
3.5
15.0
```

### 範例說明 #1

14 公克紅茶可以製作：

$14 \div 4 = 3.5$ 份奶茶

總共需要牛奶：

$3.5 \times 10 = 35.0$ 公克

目前已有 20 公克，因此還需要：

$35.0 - 20 = 15.0$ 公克

### 範例輸入 #2

```
3
8
9
10
```

### 範例輸出 #2

```
3.0
14.0
```

### 範例說明 #2

9 公克紅茶可以製作 3 份奶茶。

需要牛奶：

$3 \times 8 = 24$

目前已有 10 公克，所以還需要：

$24 - 10 = 14$
